# 🛍️ ShopIQ

> **Akıllı Fiyat Karşılaştırma ve Fiyat Takip Platformu**

ShopIQ, farklı e-ticaret platformlarındaki ürünleri tek bir yerde karşılaştırmayı, fiyat değişimlerini takip etmeyi ve kullanıcılarını en doğru satın alma zamanı konusunda bilgilendirmeyi amaçlayan modern bir web platformudur.

Kullanıcılar yalnızca ürün bağlantısını paylaşarak aynı ürünü farklı mağazalarda karşılaştırabilir, istedikleri ürünü takibe alabilir ve fiyat düştüğünde anında bildirim alabilir.

ShopIQ, React ve modern web teknolojileri kullanılarak geliştirilen bir fiyat karşılaştırma ve akıllı alışveriş asistanı projesidir.

---

# 🚀 Projenin Amacı

İnternette alışveriş yaparken aynı ürün onlarca farklı mağazada farklı fiyatlarla satılabiliyor. Kullanıcıların en uygun fiyatı bulabilmesi için her mağazayı tek tek ziyaret etmesi gerekiyor.

ShopIQ bu süreci tek bir platform altında toplayarak kullanıcıların zamandan tasarruf etmesini, doğru fiyatı bulmasını ve satın alma kararını daha bilinçli vermesini amaçlar.

---

# 💡 Neden ShopIQ?

Günümüzde fiyat karşılaştırması yapmak zaman alan ve yorucu bir süreçtir.

ShopIQ;

- Aynı ürünü farklı mağazalarda otomatik olarak karşılaştırır.
- Kullanıcının istediği ürünü takip eder.
- Fiyat değişimlerini izler.
- İndirime düştüğünde kullanıcıyı bilgilendirir.
- Kullanıcının en doğru satın alma zamanını yakalamasına yardımcı olur.

ShopIQ, sadece fiyat karşılaştırması yapan bir platform değil; kullanıcıların ürünleri uzun süre takip edebildiği, fiyat değişimlerini izleyebildiği ve en doğru satın alma zamanını yakalayabildiği akıllı bir alışveriş asistanıdır.

# ⚙️ Kurulum

Projeyi bilgisayarınıza klonlayın.

```bash
git clone https://github.com/Eminenurdogan/ShopIQ.git
```

Proje klasörüne girin.

```bash
cd ShopIQ
```

Bağımlılıkları yükleyin.

```bash
npm install
```

Geliştirme sunucusunu başlatın.

```bash
npm run dev
```
